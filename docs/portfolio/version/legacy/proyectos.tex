\textbf{Kromask} — Co-op Puzzle Game \\
\textit{\href{https://jorge-juma.itch.io/maskoop}{jorge-juma.itch.io/maskoop}}
\end{onecolentry}

\vspace{0.20 cm}
\begin{onecolentry}
\begin{highlights}
\item Originated at a game jam (released on itch.io as \textit{MaskOop}) and later funded by the university for continued development as \textit{Kromask}.
\item Co-op puzzle game built around mask-swapping mechanics, where each mask grants the player a different ability.
\item Built the in-engine map editor used by the team to author levels, the event manager coordinating gameplay events, and the signal system wiring interactable map elements to their triggers.
\item Took on an organizational role within the programming team during the early phase, coordinating tasks in the absence of a dedicated production team.
\item \textbf{Stack:} Unity, C\#.
\end{highlights}
\end{onecolentry}
